# 家居风水系统 · 原型首版 v0.1.0

这是用户确认的纯白空间罗盘原型，作为独立 GitHub 分支 `codex/prototype-v0.1.0` 与标签 `v0.1.0` 存档。仓库主分支已有更高版本的另一条开发线，本版不覆盖或回退主分支，也不代表线上生产版本。

## 本地启动

使用 Node.js 22.12+（建议 22 LTS）。

```bash
npm ci
npm run dev:prototype -- --port 5178
```

打开 http://127.0.0.1:5178/ 。此启动方式只运行原型前端，不需要账户服务或数据库。

```bash
npm run build
npm run preview
```

## 已可用

- 桌面与手机响应式纯白空间罗盘，360 条刻度、八宫卦象、十二地支与生成生肖图片。
- 南上北下、东左西右；真实方位角保持北 0/360°、东 90°、南 180°、西 270°。展示偏移不改写历史校准角度和节点。
- 初始工作台无默认户型；上传、更换、移除图片，方位校准，手动点选及拖动轮廓节点、撤销、图层与缩放。
- 本机历史包含图片、角度、轮廓、图层与编辑阶段；可刷新后重新打开、重命名、删除。移除工作台图片会保留历史记录。
- 账户设置、设备显示名称保存、关于软件页面。版本由 `package.json` 经 `src/version.js` 统一读取。

## 原型边界

- 图片和历史保存在当前浏览器的 IndexedDB，显示名称保存在 localStorage；无云同步。清除网站数据会删除本机记录，浏览器/设备之间不互通。
- 当前页面未接通真实账户服务，不提供真实注册登录、改名或改密。密码表单和保存按钮禁用，不读取、存储或提交密码。
- 宫位只展示方位资料，分析规则待用户提供；尚无自动风水分析结论。室外功能未开放。
- 仓库保留早期 `server/`、`functions/`、旧组件和 `DESIGN.md` 等历史实现资料；它们不代表本版页面已启用的功能。`npm run dev` 是旧前端/API 联合启动入口；体验本版请使用 `dev:prototype`。
