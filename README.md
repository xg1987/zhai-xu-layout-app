# 家居风水系统 · v0.1.1

本次 GitHub 源码版本包含东方住宅云动树摇视频登录背景、透明登录注册界面、邀请审核、管理后台与模型配置/费用记录。登录背景为 1080p 无声循环视频，支持静态图回退与减少动态效果偏好。

仍沿用独立原型分支，不覆盖 main；Cloudflare 账户服务尚未适配本版后台，当前交付为 Node 本地运行版本，不代表生产部署。以下 v0.1.0 说明保留为历史记录。

这是用户确认的纯白空间罗盘原型，作为独立 GitHub 分支 `codex/prototype-v0.1.0` 与标签 `v0.1.0` 存档。仓库主分支已有更高版本的另一条开发线，本版不覆盖或回退主分支，也不代表线上生产版本。

## 本地启动

使用 Node.js 22.12+（建议 22 LTS）。

```bash
npm ci
npm run dev:local-auth
```

打开 http://127.0.0.1:5178/ 。当前工作树需要本机登录服务；GitHub v0.1.0 存档仍为原来的界面原型。

```bash
npm run build
npm run preview
```

## 已可用

- 桌面与手机响应式纯白空间罗盘，360 条刻度、八宫卦象、十二地支与生成生肖图片。
- 南上北下、东左西右；真实方位角保持北 0/360°、东 90°、南 180°、西 270°。展示偏移不改写历史校准角度和节点。
- 初始工作台无默认户型；上传、更换、移除图片，方位校准，手动点选及拖动轮廓节点、撤销、图层与缩放。
- 本机历史包含图片、角度、轮廓、图层与编辑阶段；可刷新后重新打开、重命名、删除。移除工作台图片会保留历史记录。
- 账户设置、设备显示名称保存、关于软件页面。版本由 `package.json` 经 `src/version.js` 统一读取。

## 原型边界

- 图片和历史保存在当前浏览器的 IndexedDB，显示名称保存在 localStorage；无云同步。清除网站数据会删除本机记录，浏览器/设备之间不互通。
- GitHub 存档首版未接入账户服务；当前未发布的本地工作树已接入登录与邀请码审核注册，见下方本机登录开发说明。客户端设备名称仍仅本机保存；管理员系统设置已接通账户显示名称与密码修改。
- 宫位只展示方位资料，分析规则待用户提供；尚无自动风水分析结论。室外功能未开放。
- Node 的 `dev`、`start` 与 `dev:local-auth` 已统一使用同一套账户、模型和后台服务。Cloudflare `functions/` 仍是旧实现，尚未迁移这批管理功能；本次未部署 Cloudflare。

## 本机登录开发（未发布）

运行 `npm run dev:local-auth` 同时启动 127.0.0.1:3001 本机认证服务与 127.0.0.1:5178 前端；如端口已被当前预览占用，不重复启动。仅需重启 API 时运行 `node server/local-auth.js`。若原生 SQLite 依赖缺失，运行 `npm rebuild better-sqlite3`。`start` 共用同一服务；正式 HTTPS 域名需设置 `APP_ORIGIN`，可通过 `DATABASE_FILE` 与 `VISION_MASTER_FILE` 指定持久化路径。

测试数据保存在被 Git 忽略的 `server/local-auth.sqlite`，不使用或修改旧 `server/data.db`。密码仅以 bcrypt 哈希保存；会话使用本机专用 HttpOnly Cookie。账号凭据单独交付，不包含在源码。普通用户必须使用有效邀请码注册，待管理员审核通过才能登录；现有管理员可在账号管理中创建账户。用户登录 `/login`，管理员登录 `/admin/login`。管理页按服务端角色授权，但其账号列表仍是独立本机预览资料；客户端资料页仍为设备资料；管理员 `/admin/settings` 已连接实际账号的名称、密码与版本信息。

## 图片识别配置（本机开发，未发布）

管理员登录后打开 `/admin/models`，在“图片识别”中填写对应服务的 API Key，保存后点击“测试连接”。模型与接口已预设：

- 主模型：Google AI Studio 的 `gemini-3.8-flash`，使用官方 GenerateContent 接口。
- 备用模型：阿里云百炼北京地域的 `qwen3.7-plus`，使用 `https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions`。其他地域的 Key 不适用于这个预设。
- 只配置其中一家也可使用；两家都配置时，主服务调用失败或结果格式不合规后自动尝试备用服务。没有配置时明确提示，不生成示例结果。
- 连接测试实际发起少量文本调用并检查模型响应，不能替代真实图片效果验证。保存本身不会调用外部服务。

上传图片后在“方位校准”中点击“识别方位与轮廓”。图片最长边会缩放到 2048 像素后经本机服务端提交给模型。返回的方位、轮廓和房间文字需人工核对；点击“填入校准与轮廓”才替换已识别到的项目，未知方向不会默认设为上北。原始图片与本机历史保留。缺角标准、中心算法和解释库尚未接入，本功能不生成风水结论。

API Key 只在服务器端使用，AES-256-GCM 加密后存入被忽略的本机数据库。解密文件 `server/.vision-master-key` 首次保存时生成，权限 0600，已被 Git 忽略；不得发布或提交。配置读取只返回是否保存与上次测试状态，不回传密钥。浏览器不持久保存密钥，外部服务错误正文不转发给客户端。数据库和解密文件需作为一组妥善保留；当前仍是本机服务，不代表云端生产部署。

验证：`node --test server/vision.test.js`（隔离数据库与模拟服务响应，无真实计费调用），`npm run build`。覆盖角色权限、加密存储/重启恢复/删除、错误响应脱敏、备用切换、图像和坐标校验及南上北下坐标映射。

接口参考：[Gemini 3.8 Flash](https://ai.google.dev/gemini-api/docs/generate-content/latest-model)、[Google 结构化输出](https://ai.google.dev/gemini-api/docs/generate-content/structured-output)、[百炼兼容接口与地域](https://www.alibabacloud.com/help/en/model-studio/compatibility-of-openai-with-dashscope)。

## 模型用量与人民币费用

管理员 `/admin/usage` 查看本服务启用记账后的逐次调用。识别、连接测试、主备重试分别记账，同一识别的多次请求共享 requestId。记录含账号、模型、时间、输入/缓存/输出/思考 Token、结果、当时单价及汇率；不保存密钥、图片或模型原始回答。普通用户不能读取费用接口。旧调用没有保留用量，不能补造费用。

计费使用服务商返回的 usage：Gemini 输出包含 candidatesTokenCount + thoughtsTokenCount；千问 completion_tokens 已包含思考，不重复相加。缓存从总输入中拆出计价。人民币金额按纳元整数累计、页面显示至小数点后 6 位，避免每次四舍五入到分丢失小额费用。无用量或超时记“待核对”，不能认定免费；响应格式错误但有用量仍入账。进程异常退出的调用重启后标为中断。

价格于 2026-09-17 核对：Gemini 3.8 Flash Standard 输入/缓存/输出为 0.75/0.075/3.75 美元每百万 Token，官方已公布 2027-01-01 起翻倍；千问北京地域按公开原价估算，≤256K 为 2/0.4/8 元，>256K 为 6/1.2/24 元。千问限时折扣、免费额度、抵扣、税费未纳入，金额是成本参考，不是服务商实际扣款或发票。当前调用不启用工具、显式缓存存储或 Batch。价格策略在 `server/usage.js`，须随官方价格变化维护；历史记录持有价格快照。

美元自动使用 [Frankfurter / ECB](https://frankfurter.dev/) 的 USD/CNY 日汇率，无需第二个密钥；保存汇率日期与来源。汇率不可用时保留用量，管理员刷新费用记录时按调用日期补换算；不使用任意固定汇率或把缺失金额填为零。人民币模型无需外部汇率。此功能仅统计通过当前本机服务调用的模型，不包含同一 Key 在其他软件中的用量。

依据：[Google 定价](https://ai.google.dev/gemini-api/docs/pricing)、[Gemini 用量字段](https://ai.google.dev/api/generate-content#UsageMetadata)、[阿里云北京地域定价](https://help.aliyun.com/zh/model-studio/model-pricing)、[千问隐式缓存计费](https://help.aliyun.com/zh/model-studio/context-cache)。

验证：`node --test server/vision.test.js server/usage.test.js` 使用隔离数据库和模拟用量，覆盖计价/缓存/思考、主备记账、汇率失败恢复、权限、分页和沪时区日期边界，无真实付费请求。

## 管理员系统设置

后台使用固定侧栏导航，底部“系统设置”与顶部当前账户均进入设置页，不提供返回客户端入口；版本与退出登录集中在 `/admin/settings`。设置页包含当前登录账号/角色、可保存的显示名称、登录密码修改、软件名称/版本/界面语言，以及退出登录。版本从 package.json 读取。

密码修改需当前密码、新密码及再次确认。服务端校验长度、匹配和旧密码，保存 bcrypt 哈希并事务撤销此账号所有登录会话；成功回到管理员登录页。并发修改及旧密码登录竞争均有校验，错误密码尝试按账号限制。验证仅操作隔离测试账号，用户现有密码未修改。普通用户不能进入管理员设置，资料/密码接口只允许操作当前登录账号。客户端旧资料页尚未接这些接口。

验证：`node --test server/account-settings.test.js server/vision.test.js server/usage.test.js`；覆盖权限、资料存储、密码校验/更新、旧密码失效、会话撤销、并发修改及错误尝试限制。

## 管理后台与邀请审核（当前工作树，未发布）

- `/admin/overview`：真实账号统计、今日调用及人民币费用、模型连接状态、最近操作。
- `/admin`：服务端账号列表、搜索与分页、新建、编辑、启停、角色调整、密码重置；待审核与未通过分类。
- `/admin/invitations`：创建邀请码、设定使用人数和到期时间、启用/停用；新邀请码完整值只显示一次，可复制邀请码或注册链接。数据库仅存摘要与尾号。
- `/admin/events`：账号变更、注册审核、模型配置等操作记录，可按操作人或对象搜索。不记录密码、API Key 或图片内容。
- 公开注册只允许普通用户：验证邀请码 → 创建待审核账号（不颁发会话）→ 管理员通过或拒绝 → 通过后允许登录。拒绝需说明原因；无效、停用、过期、次数用尽的邀请码无法注册。并发注册不会超用邀请码。
- 停用、调整角色、重置密码都会撤销目标账号现有会话；管理员不能停用自己或撤销自己的管理权限。登录增加尝试次数限制。
- 数据升级只添加字段和新表，已有账号默认保留启用及已通过状态；原密码、模型密钥和历史计费记录保留。旧浏览器预览账号不自动提升为真实账户。
- 新建账号属于管理员主动开通；用户自行注册必须经过邀请码与审核。客户端历史隔离、云端户型记录、分析规则与 Cloudflare 适配不属于本轮完成项。

验证：`node --test server/*.test.js` 与 `npm run build`；隔离数据库测试账号权限、会话撤销、并发注册、审核门禁、邀请码失效及日志保密性。页面审核使用独立临时数据库，未修改现有账号密码或权限。

后台视觉参考：60fps.design 的中性色层次、[Airbnb 标签切换](https://60fps.design/shots/airbnb-tactile-tab-button-interaction)及 [Opal 复制反馈](https://60fps.design/shots/opal-code-copied-text-pop-interaction)。使用统一字级、圆角和表面层次，分类切换提供选中反馈，侧边面板轻量进入，复制成功就地反馈；遵循减少动态效果偏好。保持已有功能和白底风格。
