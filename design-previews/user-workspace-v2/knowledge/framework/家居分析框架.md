# 家居分析框架

版本：1.1 · 2026-09-22

## 总体结构

**住宅资料 → 方位与空间确认 → 家庭成员关联 → 分模块分析 → 调整方案 → 家居报告**

围绕三个问题展开：房子各处是什么情况、家人如何安排、具体可以怎样调整。

## 资料结构

### 住宅

保存户型图片、楼层、朝向、外墙轮廓、尺寸来源及用户确认状态。复式和多层住宅逐层记录。

### 空间与对象

每个房间有独立编号，记录用途、边界、门窗、所在楼层。床、书桌、沙发、镜子和灶具分别关联所属房间，并记录位置、朝向与是否可移动。

房间可以跨多个方位，分别保存覆盖关系，不强行归到单一方位。平方米、距离和通行宽度需要真实尺寸。

### 家庭成员

记录称呼、居住情况、现住房间、共住关系和使用需求。家庭角色由用户确认；传统家庭方位对应、卧室选择、床头朝向分别保存。

老人照护、儿童同住、轮椅通行等作为独立居住需求。出生资料只在用户选择确实需要这些资料的取法时补充。

### 成员事项

每位成员可选择婚恋桃花、夫妻相处、考试学业或事业发展目标，记录目标日期、当前关系阶段、职业及是否接受暂时换房。只有目标所需的个人资料才填写。

先匹配人物和事项，再核对方位与入住条件。同一方位可以有多个不同主题的条目；个案时间不转换成统一年龄，共住或目标冲突单独列出。

### 规则

每条规则对应一个模块，保存适用条件、所需资料、判定方法、结果文字、调整建议、来源和版本。不同取法各自成组；同一模块的一次分析使用明确选定的一组规则。

### 分析结果与方案

一条结果可以关联多个方位、房间、家具和家庭成员，并在户型图中定位。方案保存原布局与建议布局，以及调整范围：移动家具、改变房间用途或装修。

## 报告结构

| 报告部分 | 用户看到的内容 |
|---|---|
| 住宅总览 | 户型图、确认方位、已完成分析范围 |
| 八方情况 | 各方位是否完成判断、缺角情况、空间用途 |
| 家庭成员 | 每位成员现住房间、关联结果、可选安排 |
| 房间与家具 | 每个空间内的位置关系及具体建议 |
| 专题分析 | 已完成的人物事项、门主灶、学习办公、软装、舒适度、室外及年度分析 |
| 调整方案 | 建议做什么、涉及谁、改哪里、所需调整范围 |
| 前后对比 | 原布局与建议布局的图上对照 |

同一份报告支持三个入口：**按人看、按房间看、按问题看**。

每条结果采用统一结构：**结果标题 → 图上位置 → 关联成员或空间 → 解读 → 调整建议**。

只展示已获得的内容。资料不齐时给出对应的补充入口；未分析的模块不显示为“正常”。报告正文保持简洁，规则出处与版本收进可展开的依据详情。

## 分析流程

1. 上传户型图，识别外墙、房间及可见对象。
2. 确认北向、轮廓、房间用途；有误时直接修正。
3. 添加家庭成员及现住安排。
4. 选择分析模块，按需补充照片、尺寸或年份等资料。
5. 检查所需资料和可用规则，分别完成各模块分析。
6. 生成图上标记、成员关联和调整方案。
7. 用户修改布局后保留原方案，并可对照查看新方案。

## 规则库连接

现有资料继续沿用原知识库：

- 八方、卦象、五行与家庭对应：`fengshui_direction_correspondences`。
- 缺角判定与缺角解读：`fengshui_knowledge_rules`。
- 人物与事项象义：`fengshui_scenario_rules`；出处关系：`fengshui_scenario_rule_sources`。
- 规则出处：`fengshui_knowledge_sources`、`fengshui_rule_sources`。

新增方向先建立模块和规则位置，后续逐条填入你的判定标准。已有的三种缺角方法分别保留，当前不选默认方法。

模型负责识别图片中的对象；方位计算和结论调用按照已确定的规则完成。现有八方面积占比作为几何数据保留，缺角比例另行计算。

## 模块状态

| 状态 | 含义 |
|---|---|
| 未选择 | 本次没有选择此模块 |
| 待补资料 | 缺少该模块需要的住宅、成员或现场资料 |
| 待定规则 | 资料已具备，判定方法或规则尚未确定 |
| 可分析 | 资料和规则均已具备 |
| 分析中 | 正在处理 |
| 已完成 | 该模块完成，并记录本次使用的资料与规则版本 |
| 需核对 | 有识别不确定、对象冲突或方案冲突，需要确认 |
| 处理失败 | 本次处理未成功，可以重试 |
